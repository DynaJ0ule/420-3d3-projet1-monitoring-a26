# Projet 1 — Tableau de bord de monitoring système

Application de surveillance des ressources système (CPU, RAM, disque) avec interface graphique tkinter.

## Installation

Dans un environnement virtuel:

```bash
pip install -r requirements.txt
```

## Lancement

```bash
python app.py
```

## Travail à faire avant le cours

1. Forkez ce dépôt dans votre compte GitHub
2. **Lisez attentivement le code** — vous aurez un quiz de compréhension en début de cours
3. Posez-vous les questions suivantes :
   - Que fait la méthode `rafraichir()` exactement ?
   - Que se passerait-il si on voulait ajouter une alerte sonore quand le CPU dépasse 80% ?
   - Que se passerait-il si on voulait afficher les métriques dans une deuxième fenêtre en même temps ?
   - Y a-t-il des portions de code qui se ressemblent beaucoup ?
